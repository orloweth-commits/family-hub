- `caveat.woff2`: Copyright 2014 The Caveat Project Authors (https://github.com/googlefonts/caveat)
- `fredoka.woff2`: Copyright 2016 The Fredoka Project Authors (https://github.com/hafontia/Fredoka-One)

- `cormorant-garamond.woff2`: Copyright 2015 The Cormorant Project Authors (https://github.com/CatharsisFonts/Cormorant)
- `noto-emoji.woff2`: Copyright 2013 Google LLC (https://github.com/googlefonts/noto-emoji). The Light (300) weight, whole, not a Latin subset. Changed from the original in one way: the character map also lists each emoji with the two presentation selectors (U+FE0E, U+FE0F), so a browser uses these line drawings where the text asks for the emoji style.
